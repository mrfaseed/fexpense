# Security Policy

## Supported Versions

Only the latest release of FExpense is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

The FExpense team and community take the security of our application and users' data seriously.

If you believe you have discovered a security vulnerability or sensitive data exposure in FExpense, please do **NOT** report it through a public GitHub issue.

Instead, please follow responsible disclosure practices:
1. Open a **GitHub Private Vulnerability Report** via the **Security** tab of the repository: [github.com/mrfaseed/fexpense/security/advisories/new](https://github.com/mrfaseed/fexpense/security/advisories/new).
2. Alternatively, reach out directly to the maintainer via GitHub profile [@mrfaseed](https://github.com/mrfaseed).

### What to include in your report:
- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions to reproduce the issue (including proof of concept or sample payload where applicable).
- Target platform(s) affected (Android, Windows, iOS, Web, macOS, Linux).
- Any suggested remediations or mitigations.

### Response Timeline
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide status updates as we evaluate and prepare a patch.
- We kindly ask that you keep information about the vulnerability confidential until a coordinated security patch is released.
